Conocer los conceptos

La idea detrás de Git

Git es un sistema de control de versiones distribuido. Cada cambio queda registrado y podés volver a una versión anterior cuando lo necesites.

1

Commit

Una fotografía con nombre de los cambios que querés conservar en la historia.

2

Branch

Una línea de trabajo independiente para crear una funcionalidad o probar una idea.

3

Merge

La unión de una rama con otra para incorporar el trabajo terminado al proyecto principal.

Un flujo simple

git add
Prepará cambios
→
git commit
Guardá historia
→
git push
Compartí trabajo
Git no reemplaza el criterio: hace visible la historia de tus decisiones.
