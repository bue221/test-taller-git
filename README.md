# Taller de Git

Una página web estática para aprender los fundamentos de Git de forma visual: qué registra un commit, para qué sirven las ramas y cómo se integran cambios con merge.

## Contenido

- Qué es Git y por qué ayuda a mantener la historia de un proyecto.
- Conceptos fundamentales: `commit`, `branch` y `merge`.
- Un flujo inicial con `git add`, `git commit` y `git push`.
- Animaciones CSS y diseño adaptable para pantallas pequeñas.
- Un bloque práctico con comandos para crear y publicar tu primer commit.

## Inicio rápido

1. Cloná el repositorio.
2. Abrí `index.html` en el navegador.

En macOS también podés ejecutarlo desde la terminal:

```bash
open index.html
```

## Estructura

| Archivo | Propósito |
| --- | --- |
| `index.html` | Contenido y estructura de la guía. |
| `style.css` | Estilos, animaciones y adaptación a pantallas pequeñas. |

No requiere instalación ni dependencias.
