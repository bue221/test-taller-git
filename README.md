# Taller de Git

Este repositorio contiene una página web introductoria sobre Git. Su objetivo es presentar, de forma visual y breve, los conceptos básicos para empezar a entender el control de versiones.

## Contenido

- Qué es Git y por qué ayuda a mantener la historia de un proyecto.
- Conceptos fundamentales: `commit`, `branch` y `merge`.
- Un flujo inicial con `git add`, `git commit` y `git push`.
- Animaciones CSS y diseño adaptable para pantallas pequeñas.

## Cómo verlo

1. Cloná el repositorio.
2. Abrí `index.html` en tu navegador.

No requiere instalación ni dependencias.
